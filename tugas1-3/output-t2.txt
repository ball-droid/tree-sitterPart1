Tugas 2 — Penjelajah node: hasil verifikasi
===========================================

1. Uji kecil.py (satu baris `x = 1`)
   Output jelajah.py:
     module [1:0]
       expression_statement [1:0]
         assignment [1:0]
           left: identifier [1:0]
           right: integer [1:4]
   COCOK PERSIS dengan output contoh di materi (termasuk label field
   `left:`/`right:` dan posisi baris:kolom).

2. Uji fungsi.py (satu fungsi def sapa(nama)) — output wajar:
     module [1:0]
       function_definition [1:0]
         name: identifier [1:4]
         parameters: parameters [1:8]
           identifier [1:9]
         body: block [2:4]
           return_statement [2:4]
             identifier [2:11]

3. Uji file Python nyata >= 100 baris:
   J:/treesitter/repo-uji/requests/src/requests/sessions.py (920 baris,
   dari repo open source psf/requests, hasil git clone).
   Output lengkap: output-t2-besar.txt (3.576 baris node bernama).

4. [Pengayaan] Versi TreeCursor (jelajah_cursor.py) vs versi rekursif:
   - diff output-t2-kecil.txt output-t2-kecil-cursor.txt        -> identik
   - diff output-t2-besar.txt output-t2-cursor.txt              -> identik
   Kedua versi menghasilkan output byte-for-byte identik.

5. Pengecekan manual beberapa bagian output besar terhadap file sumber:
   - `class_definition [127:0]`  -> sessions.py baris 127 kolom 0 memang
     `class SessionRedirectMixin:` (kolom 0). ANGKA BARIS COCOK.
   - `name: identifier [127:6]`  -> nama kelas `SessionRedirectMixin`
     dimulai kolom 6 pada baris itu. KOLOM COCOK.
   - `class_definition [395:0]`  -> baris 395 memang
     `class Session(SessionRedirectMixin):`. COCOK.
   - `future_import_statement [9:0]` + `name: dotted_name [9:23]` ->
     baris 9 adalah `from __future__ import annotations`; `annotations`
     dimulai kolom 23. COCOK (field module_name vs name juga benar:
     `__future__` ada di module_name [9:5]).
   - `string [1:0]` dengan anak `string_start [1:0]`, `string_content
     [1:3]`, `string_end [7:0]` -> docstring memang membentang baris 1-7.
     COCOK.
   - Kedalaman: node anak `module` di-indentasi 2 spasi (kedalaman 1),
     cucu 4 spasi (kedalaman 2), dst. — konsisten di seluruh output.

Kesimpulan: semua node bernama tercetak ber-indentasi benar pada file
920 baris; versi TreeCursor identik dengan versi rekursif; posisi dan
field yang diperiksa manual semuanya cocok dengan file sumber.
