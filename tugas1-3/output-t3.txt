CATATAN PENTING (aturan "jangan menebak nama node")
---------------------------------------------------
Nama node import TIDAK ditebak: file impor.py di-parse dengan
jelajah.py dulu, dan hasilnya menunjukkan:
  import_statement [1:0]        -> name: dotted_name
  import_from_statement [2:0]   -> module_name: dotted_name
                                   name: dotted_name
Dari situlah query import.scm ditulis. Perhatikan beda field:
`module_name:` untuk modul yang di-import, `name:` untuk simbol yang
di-import — tebakan tanpa melihat pohon hampir pasti salah di sini.
