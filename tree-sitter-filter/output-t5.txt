   `parser-directories` ditambahi folder INDUK grammar:
   "J:\\treesitter\\tree-sitterPart1" (berisi tree-sitter-filter/,

2. tree-sitter.json: "file-types": ["filter"] sudah benar (hasil

Hasil `tree-sitter highlight contoh.filter` (dijalankan dari J:/treesitter,
di LUAR folder grammar, membuktikan discovery via parser-directories).
Kode ANSI di output-t5-mentah.txt; pemetaan warnanya:

  token di contoh.filter        capture              warna (ANSI)
  ---------------------------   ------------------   -------------
  status/priority/owner/...     @property            38;5;124
  =  >  >=                      @operator            tebal 38;5;239
  "open" "budi" "invoice" ...   @string              38;5;28
  and or not in contains        @keyword             38;5;56
  2  4.5                        @number              tebal 38;5;94
  true                          @constant.builtin    tebal 38;5;172
  (  )  ,                       @punctuation.*       38;5;239

Semua jenis token di file contoh berwarna BERBEDA satu sama lain:
124 / 239-tebal / 28 / 56 / 94-tebal / 172-tebal / 239.
Catatan: pada tema default bawaan init-config, @constant.builtin
(boolean) dan @number kebetulan sama-sama warna 94, sehingga boolean
diganti ke 172 di tema (config.json) agar terlihat beda.

  token di contoh.filter ter-capture dengan nama yang benar

  6 string, 8 keyword, 2 number, 1 constant.builtin).
